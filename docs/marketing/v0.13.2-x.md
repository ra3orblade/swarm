Swarm v0.13.2 is out. A patch, and mostly the last of what the React rewrite dropped.

I put the old dashboard and the new one side by side against the same database and diffed every
view pixel by pixel. Ten things had slipped: the range switch on Spend and Timeline no longer
showed which range was on, chips had lost their outline, the project menu had no "Settings…", the
session sidebar had lost its cost-per-turn strip and messages. All back.

One I liked fixing: dragging a pinned project to reorder it worked in the browser and never in the
desktop app. Tauri installs its own drag-drop handler on the webview and swallows the drop. Pointer
events get through, so the rows use those now, and the neighbours slide out of the way, which
native drag could never animate.

The session log also reads newest-first now. Scroll into the history and the row under your eyes
stays put when new rows land above it.

Local-first, open source, no account. One command:
bunx @ra3orblade/swarm setup

Release notes: https://getswarm.vercel.app/changelog
Downloads: https://getswarm.vercel.app/#downloads
