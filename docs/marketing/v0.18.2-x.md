Swarm v0.18.2 is out. A patch, mostly for the desktop app's updater.

I opened the app the morning after 0.18.1 and it told me none of the fallback platforms were found. The release workflow builds three desktop legs, and each one merged its platforms into the updater manifest by downloading the file, deleting it and uploading its own. Linux and Windows finished one second apart, so one read the gap the other left and the last upload won with its own platforms only. The manifest is now rebuilt once from the signature files on the release, after all three legs, and the 0.18.1 one was repaired in place. Also in: the Stats activity strip came up as an empty box because the News calendar had borrowed its class names, and two Dependabot alerts got their fixes.

Local-first, open source, no account. One command:
bunx @ra3orblade/swarm setup

Release notes: https://getswarm.vercel.app/changelog
Downloads: https://getswarm.vercel.app/#downloads

## Thread (optional follow-ups)

1/ The rebuild script is `tools/updater-json.ts`. It reads every `.sig` asset on the release and writes the same nine platform keys, URLs and signatures tauri-action writes. I checked it key for key against the 0.18.0 manifest before trusting it with 0.18.1.

2/ The class clash got past `check:classes` because that check only asks whether a className has a rule somewhere, not whether two components share one. The calendar has its own names now; the strip is back to its 53 columns.

3/ zod moves to 4 in the MCP server, since 3.x has no patched release for the uncapped-array advisory. rustls moves to 0.23.46 in the desktop crate. The third alert, glib on Linux, waits on Tauri's GTK bindings.
