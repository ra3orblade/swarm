Swarm v0.14.0 is out. Until now it watched agents; now it can steer them.

The thing I wanted most: an agent that cannot tell me it's done while the tests are red. Set
`on_stop = "block"` and when Claude Code finishes a turn in a claimed worktree, Swarm runs the
repo's required gates first, and while one fails it refuses the stop and hands back the gate's name
and the tail of its output. The agent reads that and keeps working. Three refusals and it stops
anyway with an incident, because a rule that can loop forever is a rule that burns your budget.

The same idea runs through the rest: permission prompts from your terminal sessions now show up on
the dashboard with Allow / Deny, two agents editing the same file hear about each other the moment
the edit lands, a message sent to an idle session wakes it instead of waiting for its next tool
call, and a rule can rewrite a command instead of refusing it — `git commit --no-verify` quietly
loses the flag.

Local-first, open source, no account. One command:
bunx @ra3orblade/swarm setup

## Thread (optional follow-ups)

1/ The rewrite rules nearly shipped with a hole I'm glad I looked for. `kubectl delete ns prod &&
rm -rf /tmp/x` came back as `… && rm -rf /tmp/x --dry-run=client`. The flag landed on the wrong
command, the namespace was deleted, and the incident feed cheerfully recorded the call as made
safe. A rewrite now refuses to touch anything with a `&&`, a pipe or a redirect in it.

2/ Worse, a rewrite used to answer Claude Code with "allow", which approves the *whole* tool call —
so anything chained behind it ran with no prompt at all. The rewritten command is now put back
through the rules, and the second pass wins.

3/ Both of those came out of reading the release's own diff for performance and correctness before
tagging it. Also found: a five-minute stall on every turn once the repair loop gave up, a config
file the daemon wrote that it then couldn't see for 30 seconds, and a team daemon pid trusted
across reboots — which would have aimed a SIGTERM at whatever process inherited the number.
