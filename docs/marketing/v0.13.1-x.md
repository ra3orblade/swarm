Swarm v0.13.1 is out. Mostly things the React rewrite had quietly dropped.

I noticed the first one myself: the "+" in the project sidebar had turned into a bare path box.
The folder browser behind it was gone, and so was dragging pinned projects into the order I
wanted. Both are back. The sidebar also resizes now, which it never did — a long project name was
an ellipsis with no way to see the rest.

Under that, the dashboard stopped re-downloading a 195 KB state blob every five seconds when
nothing changed. An unchanged poll is a 304 with no body now.

Local-first, open source, no account. One command:
bunx @ra3orblade/swarm setup

Release notes: https://getswarm.vercel.app/changelog
Downloads: https://getswarm.vercel.app/#downloads

## Thread (optional follow-ups)

1/ One rule gap worth knowing about: `git -C /some/worktree reset --hard` used to walk past every
git guard, because the guards matched `git` immediately followed by the subcommand. Git's global
options in between (`-C`, `--git-dir`, `-c`) are handled now.
