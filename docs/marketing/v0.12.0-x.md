## Thread (optional follow-ups)

1. It also looks for the opposite: files several different sessions keep re-reading and almost never edit. Those are the ones whose conclusion belongs in CLAUDE.md, written down once instead of re-derived in every window. On my machine it found none, correctly — everything multiple sessions read here is also something they were editing.

2. Two things in this release are the roadmap being wrong and the code saying so. It wanted repeated tool cycles to feed the stuck detector — but `Read → Edit → Read → Edit` is the most ordinary thing an agent does, so a cycle only counts when the calls inside it are failing.

3. And it wanted deadlock detection on held resources. A deadlock can't happen: claims fail closed, so a second claimer is refused rather than queued and nobody ever blocks. What can happen is two agents each wanting what the other holds — so Swarm now records refusals, which it never did before.

4. Also: the dashboard can now tell you when it has broken, instead of leaving the last screen up looking current. If a route 404s because you updated the page but not the daemon, it says that, rather than spinning forever.
