Swarm v0.15.1 is out. A patch: five things I found in the week after 0.15.0.

The one that surprised me: Grok CLI 1.0.40 started running the hooks in `~/.claude/settings.json`. Swarm's hook was suddenly running inside Grok and reading the payload as Claude Code's. Ending a Grok session hung, because the wake hook long-polls in the background under Claude Code and in the foreground under Grok, for up to an hour. Grok sessions also showed up as Claude Code. Swarm reads Grok's payload now, and its tools map onto the rules like Codex's and Gemini's do.

The one I should have caught earlier: the desktop app sat at 30–45% CPU doing nothing. The active status dots pulsed by animating `box-shadow`, which repaints every frame, in every view, forever, even with the window behind others. The pulse runs on the compositor now. 300 style recalculations per five seconds became 2.

And a small feature: the dock badge counted questions and permission prompts waiting on you, but the only place to answer them was the asking session's page, and most prompts expired before you got there. There's a "N waiting" pill in the header now that opens all of them in one panel, answerable in place.

Local-first, open source, no account. One command:
bunx @ra3orblade/swarm setup
