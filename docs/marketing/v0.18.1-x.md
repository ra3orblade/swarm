Swarm v0.18.1 is out. The security news reads like a paper now.

I shipped the News view this morning as a table, opened it after lunch, and did not read a single headline. A table is for sorting, not reading. So it is a paper now: a dateline for each day that sticks to the top while you scroll, the day's lead stories across the width with their pictures, the next few in a row, the rest as briefs. The pictures were the hard part — half the security feeds don't carry one — so the daemon reads each article's page once for its Open Graph image. There is a switch for that, and one for OSV advisories, which until today meant pasting two lines of TOML.

Local-first, open source, no account. One command:
bunx @ra3orblade/swarm setup

Release notes: https://getswarm.vercel.app/changelog
Downloads: https://getswarm.vercel.app/#downloads

## Thread (optional follow-ups)

1/ The switch writes `~/.swarm/settings.toml`, a file the daemon owns, layered under your `config.toml`. Anything you wrote by hand still wins, and when it does the button is replaced by the name of the file to change. The daemon never edits `config.toml`.

2/ A month calendar sits beside the paper, each day shaded by how many articles it holds. Click a day and both the paper and the table narrow to it. On my machine October has 78 articles over 18 days that name something a project of mine runs.

3/ Pictures: the feed's own, or the article page's `og:image`, read once with the same user agent as the feed and never asked again. `[security] pictures = false` keeps the daemon to the feeds. The privacy page says exactly what leaves the machine either way.
