Swarm v0.13.0 is out. The dashboard is a React app now.

I'd been ignoring a flicker every five seconds. When I finally measured it: 1,059 elements
thrown away and recreated, to update eleven text nodes. That's what a full repaint on every
poll costs. It also meant an open menu or a half-typed filter got destroyed four times a minute.

Now the same poll mutates nothing when nothing has changed.

Nothing about the interface moved — every view, column and action is where it was.

Local-first, open source, no account. One command:
bunx @ra3orblade/swarm setup

Release notes: https://getswarm.vercel.app/changelog
Downloads: https://getswarm.vercel.app/#downloads

## Thread (optional follow-ups)

1/ The rewrite is also where I learned what a silent CSS regression costs. React mounts inside a
`#root` div. It's `display: contents`, so it leaves the layout — but not the selectors. Every
`body > aside` rule stopped matching, and the sidebar lost its padding, border and background.
Nothing errored. The rule just went quiet. There's a build check for that shape now.

2/ Same shape, different file: `.br` — the monospace treatment for a branch name — was only ever
written as `td.br`. The port moved it to a `<span>` inside the cell, so it matched none of its
eleven call sites and every branch name quietly rendered in body sans.

3/ Both are the same lesson. A missing rule doesn't fail — it just stops applying, and you find
out when someone sends you a screenshot.
