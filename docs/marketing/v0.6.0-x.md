## Main post

Your laptop slept. The agent that was halfway through the login form is gone — context full, terminal closed, no notes.

Open the session in Swarm. It already wrote the handoff for it: the three files it edited, the `bun test auth` it last ran, the last thing it said. One button: **Resume where it died.** A new agent starts in the same worktree, reads that, and carries on.

That's Swarm 0.6.0. The data it's been collecting starts paying you back.

Local-first, open source, one command. getswarm.vercel.app

## Thread

1/ Replay. Pick any session and step through what the agent actually did, one tool call at a time — the Write's contents, the Bash command and what came back. No more guessing from a summary.

2/ Cost by task. The Spend view now says what each *ticket* cost, not just each session. And a Context budget table ranks sessions by how much they re-read the same material — the agents quietly burning your cache.

3/ A rule keeps asking about `pkill -f vite` and you keep saying yes. Dry-run it: Swarm replays your project's real history under any rule modes and shows what would have fired — and flags the flaky ones, the rules that ask and are always allowed. Decide with evidence, then paste the `.swarm.toml` line Codify wrote for you.

4/ Your backlog lives in GitHub Issues or Linear, not a markdown file? `[tasks] source = "github"` (via your logged-in `gh`) or `"linear"` (key from your environment, never stored). Same Board, same `swarm_next_task`, closed means done, *blocked by* means a dependency.

5/ And Search. "Has anyone dealt with this before?" — handoffs, the commands rules stopped and why, gate rubrics, what past sessions said. Agents get it too, as `swarm_search`. Plain SQLite FTS5 in the one database; no model, no network, never your code.

6/ Also: native notifications when a run is waiting on you or a claim was orphaned with unfinished work, and a What's New in the app so you see this list without leaving it.
