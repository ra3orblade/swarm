Swarm v0.9.0 is out.

The main thing this release is workflows. You declare the sequence in .swarm.toml — implement, run the tests, have a second agent review the diff, open the PR — and the daemon walks a task through it. The agent does the implementing; the daemon does the checking. When a step fails it stops and files an incident instead of carrying on.

Agents can also message each other now, and me. One got stuck behind a flaky test and asked whether to rebase or fix it in place; the question showed up on its session page and I answered from there. Less babysitting, more being on call.

Gemini CLI joins Claude Code, Codex and Grok on the dashboard — same session view, same cost numbers.

The timeline stopped lying, too. It used to draw one solid bar per session. Now it draws a tick per turn, so you can see when an agent was working and when it just sat there.

If you want to look around without hooking anything up, `swarm demo` opens a dashboard with sample data.

Open source, local-first, no account.

## Thread (optional follow-ups)

- Messages are addressed, not broadcast: to a session, to whoever holds a task, or to "lead", which is me. Delivered once, on the agent's next tool call — or straight into a spawned run's stdin.
- A daemon restart marks in-flight workflows as stopped rather than pretending they're still running. Small thing, but I kept getting burned by tools that lie after a restart.
- After an upgrade the dashboard notices the newer version on disk and offers a one-click daemon restart. I hit the stale-daemon problem twice myself before fixing it.
