## Thread (optional follow-ups)

1. The icons aren't files someone drew and checked in. `tools/icons.ts` reads the robot out of `core`, rasterises it, and writes the PNGs, the `.ico` and the `.icns` itself — no image editor in the loop, so changing the drawing changes every icon.

2. The rain on the site is real rain now. Last go it was pixel columns marching in lockstep over a static grid that never moved — a full character grid now, each stream at its own speed, white leading glyph, trail dying out behind it. 0.4ms a frame, and it stops when you scroll past it.
