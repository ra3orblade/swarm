# Brand assets

Pixelart mark for Swarm. The motif reads as a swarm of agents streaming into activity rows — the Fleet view in logo form: bright leading agents, mid-green activity bars, dim motion-tails, a bright center pulse.

- `swarm-mark.svg` — the mark alone (transparent), for light or dark backgrounds.
- `swarm-icon.svg` — the app icon (mark on a dark pixel-rounded square).

Both are hand-authored from a pixel grid with `shape-rendering="crispEdges"`; scale them with `image-rendering: pixelated` to keep the pixels sharp. Palette: `#a3e635` (bright), `#7cc02f` (mid), `#4f7d24` (tail), on `#0e1013`.
