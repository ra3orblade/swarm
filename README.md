# Harness

Local-first control plane for AI-agent development on any repository.

Point it at any folder. It watches every Claude Code session on your machine, keeps a ledger of who holds which task, worktree and runtime resource, enforces the rules you'd otherwise write as prose, and streams all of it to one dashboard.
