The dashboard

Everything those sessions do lands in one place, live, across every repository on the machine.

What you get

Run more than one agent at a time and you lose the thread by lunchtime. Swarm gives you the three things you stop having.

You can see them

Every agent on the machine in one list: what it is running right now, how much it has spent, and whether it is stuck in a loop. It reads what your agents already write, so there is nothing to install in your projects and nothing to keep updated.

They stay out of each other's way

Hand Swarm a task and it starts an agent on it in a copy of your repo that is its own, so two agents can never edit the same files. When one says it has finished, Swarm doesn't take its word for it — it runs your tests itself before calling the task done.

They can't do the dangerous thing

“Never force-push”, “never delete that folder” — written in a prompt, that's a wish. Swarm turns it into an answer at the moment the agent tries, and keeps a record of every one. It's a guardrail against accidents, not a cage: if Swarm isn't running, your agents carry on as normal.
